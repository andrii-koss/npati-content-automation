## Quick start

1. Install and activate **NPATI Content Automation** in WordPress.
2. Open **NPATI** in the WordPress admin menu.
3. Sign in to your NPATI account or create an account.
4. Review and approve the requested connection permissions.
5. Open **Market**, **Hub**, or **Content** to begin.

The plugin itself is free to install and use. Connected third-party services may have their own pricing and usage terms. OpenAI is optional.
